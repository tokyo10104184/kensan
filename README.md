# 研鑽 KENSAN — 意欲を、鍛え上げろ。

自ら進んで勉強したくなる仕掛けを詰め込んだ、依存性のない単体ウェブアプリです。
スマホ / PC 両対応、データはブラウザの `localStorage` に保存されます（サーバー不要・登録不要）。

## 起動方法

このフォルダで下記を実行し、ブラウザで `http://localhost:8000` を開いてください。

```bash
cd kensan
node server.js
```

`http://localhost:8000` を開いてください（別のポートにしたい場合は `PORT=9000 node server.js`）。
`index.html` を直接ブラウザで開いても動作します。

Termux でブラウザが `localhost` に繋がらない場合は、`http://127.0.0.1:8000` を試すか、
同じ Wi-Fi の端末からなら `http://<この端末のIP>:8000` でアクセスできます（IP は `ifconfig` で確認）。

## 四つのエンジン（設計の核）

| ドライバー | 仕掛け |
|---|---|
| **意欲 MOTIVATION** | 「なぜ勉強するか」を登録し、ホームのタイマーに常に表示。タスク完了やご褒美で小さな報酬を連発。 |
| **規律 DISCIPLINE** | タイマー（ポモドーロ）、毎日リセットされる試練、朝のセッション、途切れると罰（規律 -3 / 執着 -5）。 |
| **執着 OBSESSION** | 連続日数、コンボ倍率、ヒートマップ、ライバルとの差、空いた日は四つの力が衰える。 |
| **自我 EGO** | レベルと称号（見習い→伝説）、架空の人物との勝敗、キャラ固有の挑発、コピーできる「自我的名刺」。 |

## 画面構成（迷わない導線）

| 画面 | 役割 |
|---|---|
| **今日** | 上部に「こんばんは、修行者」などの挨拶ウィジェット、その下に大型ポモドーロを配置。先頭ではレベル／連続記録の上部バーを畳んで挨拶・タイマーの領域を広げ、スクロールし始めると上部バーが引き下げられて表示されます。開始すると全画面のタイマーだけに切り替わり、1画面に収まったまま集中できます。さらに下へスクロールすると、今日の数字・タスク・四つのエンジン・週次グラフが並びます。 |
| **タスク** | デイリー試練と自分のタスクを1か所に統合。継続カレンダーもここ。 |
| **冒険** | 勉強時間をダメージに変えて魔物を倒す勉強RPG。定期試験は「1日のノルマ」を決めて毎日削るボス戦になり、3週間前から設定可能。 |
| **ライバル** | 対決中の相手を大きく表示。相手一覧はコンパクトに選択、詳細は折りたたみ。 |
| **ショップ** | 「集中を守る・加速する」「ご褒美」の2グループに整理。 |

PC ではサイドバー、スマホでは下部ナビ＋右下の「▶」ボタンから、いつでも集中を開始できます。

## 主な機能

- **集中タイマー** — アプリを開いた瞬間にホームへ大型タイマーを表示。集中 / 短休憩 / 長休憩、進捗リング、効果音、通知に対応。時間は設定画面で**1分単位に自由に手入力**できます。リロードしてもタイマーは継続。「集中を開始」でタイマーを動かすと、ナビやダッシュボードを消したタイマーだけの全画面モードへ切り替わります（一時停止でホームに戻る）。集中が終わるとリザルト画面は出さず、短いポップアップのあと自動で休憩フェーズへ。休憩が終わっても同じように次の集中へ戻り、全画面のままスムーズに学習ループが続きます。途中で抜けたいときは「⏹ 終了」を使うと、それまでの学習時間を集計したリザルト画面が出ます（コンボは途切れません）。ただし**集中フェーズを1回完遂するまでは、終了してもリザルトも報酬も出ません**。まずは一度、最後までやり切ってください。上部の「集中する」ボタンや右下の▶ボタンは、ホームのタイマーをその場で開始します。
- **効果音（始まりと終わりの合図）** — タイマー開始／一時停止／リセット、セッション・休憩の完了、タスクのチェック・解除、ショップ購入、ライバル逆転、ボス討伐など、「何かが始まる／終わる」瞬間に短い音で通知。設定の「効果音」で一括オン／オフできます。
- **コンボ & シールド** — 連続セッションで XP 倍率アップ。シールドで連続日数を1回だけ守れる。
- **デイリー試練** — 毎日リセットされる5つのクエスト。達成すると報酬を手動で受け取れる。
- **学習タスク** — 科目・難易度付き。完了で XP / 金貨獲得。
- **ライバル対決** — 架空の修行者6人（影山 蓮 / 北斗 / 千夜 / Mika / SORA / 無名）と「その日の集中時間」で1対1の対決。キャラごとの信念・挑発文・学習スタイルを用意し、Lv.に応じて解放。リアルタイムで差が表示され、逆転すると +100 XP / +80 金貨（1日1回）。毎日少しずつ強くなり、勝敗履歴も残る。
- **ショップ** — 金貨でシールド、倍率ブースト、ご褒美券などを購入。
- **設定** — 名前・「なぜ」・分身・集中時間／短休憩／長休憩（いずれも自由入力）・効果音・通知。データリセットも可能。
- **インタラクティブなオンボーディング** — 初回起動時に5ステップで「名前・なぜ・ライバル・集中時間（分を自由入力）・最初のタスク」を対話的に設定。選択肢や例文のテンプレートはなく、自分の言葉・自分の数字で入力します。完了後は画面の主要ポイントをスポットライトで案内する30秒ツアーが始まり、最後のボタンからそのまま最初の集中を開始できます。ツアーは設定画面から何度でも再生可能。
- **四つのエンジンのヘルプ** — ホームの「四つのエンジン」にある「?」を押すと、各ドライバーを上げる具体行動と下げる要因が表示されます。
- **勉強RPG「冒険」** — 魔物は集中セッションの1分が1ダメージ（コンボ倍率がそのまま乗算）。魔物を倒すと次が解放され、全討伐後は周回で敵が強化されます。定期試験はボス戦として登録でき、試験日の3週間前から挑戦可能。ボスは「1日のノルマ（1〜4セッション）× 日数 × 10ダメージ」のHPを持ち、1セッション＝10ダメージ。ノルマ未達分は翌日へ繰り越され、ノルマを超えたセッションはHPを削らずXP・金貨ボーナスになります。日ごとの達成状況は横スクロールのカレンダーで確認でき、超過分は別色のバーで表示。試験日を迎えると敗北です。戦闘記録とボス討伐数も残ります。

## 補足

初回起動時には、5ステップの対話型オンボーディングが表示されます。

1. 名前と分身（アイコン）
2. 「なぜ勉強するか」（選択肢 + 自由記述）
3. 最初のライバル
4. 1セッションの長さと最初のタスク
5. 設定の確認

完了すると、レベル表示・連続日数・ライバルとの差・タスク・集中ボタンを順に光らせるガイドツアーが始まります。最後の「集中を始める」でそのまま最初のセッションへ。ツアーは「⚙ 修行者の設定」→「使い方ガイドをもう一度見る」からいつでも再生できます。

ここで入力した「なぜ」が、モチベーションが落ちたときに何度も目に入る設計になっています。
